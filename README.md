# captcha-reader

浏览器自动化中遇到图形验证码时，截取验证码元素并经放大、灰度、二值化等图像增强提升 AI 视觉识别率，再自动填入（浏览器侧的截图/填值动作复用浏览器控制能力，本技能只负责图像增强与识别）。

## 使用

这是豆包（及兼容 Agent）的**本地技能（Skill）**。完整能力、触发场景与操作流程见入口文档 **[`SKILL.md`](SKILL.md)**，Agent 命中时首先读取它；下列子目录按需加载，不必一次全读。

## 目录

- `SKILL.md`：技能入口与路由
- `scripts/`：随技能分发的可执行脚本
